# ListCheck

**Planning only; implementation is not activated.** The public repository exists at [123ssk321/cv-listcheck](https://github.com/123ssk321/cv-listcheck), as verified by the parent project. No application, dataset, benchmark results, or deployment is claimed here.

ListCheck is a proposed browser-local catalog photo preflight assistant for small sellers and catalog agencies. It will check image dimensions and aspect ratio, measure border background, and provide conservative crop and sharpness warnings with visible evidence. Its value hypothesis is faster, repeatable catalog review.

The initial domain is opaque, single-product photos on a plain background. OCR, barcode readability, semantic object counting, automatic editing, marketplace certification/integrations, pretrained models, cloud uploads, server APIs, accounts, and billing are excluded.
